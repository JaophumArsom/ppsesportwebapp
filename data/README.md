# ข้อมูลเว็บไซต์ (Data)

โฟลเดอร์นี้เก็บข้อมูลทั้งหมดที่ **แก้ไขได้จากหน้า `/admin`** ไฟล์เป็น JSON ธรรมดา
อ่านง่าย แก้ไขด้วยมือได้ และเว็บไซต์จะอ่านค่าสดทุกครั้งที่มีการเรียก

## ไฟล์ทั้งหมด

| ไฟล์ | เก็บอะไร | แก้ได้จาก |
| --- | --- | --- |
| `members.json` | สมาชิก / นักกีฬา / โค้ช | แท็บ **สมาชิก** |
| `achievements.json` | ผลงานการแข่งขัน | แท็บ **ผลงาน** |
| `games.json` | สายเกม (ภาพปก / โลโก้) | แท็บ **โลโก้เกม** |
| `branding.json` | โลโก้ทีม / โลโก้โรงเรียน / ชื่อ | แท็บ **โลโก้ทีม/โรงเรียน** |
| `hero.json` | รูปพื้นหลังหน้าแรก (เลื่อนไปทางซ้าย) | แท็บ **โลโก้ทีม/โรงเรียน** |

## วิธีที่แนะนำ: ใช้หน้า Admin

เปิด **http://localhost:3000/admin** แล้วเลือกแท็บที่ต้องการ
ข้อมูลจะถูกบันทึกลงไฟล์ JSON อัตโนมัติ และหน้าเว็บแสดงผลใหม่ทันที
**ไม่ต้อง build ใหม่ ไม่ต้องแก้โค้ด**

> ⚠️ หน้า Admin ยังไม่มีระบบล็อกอิน — ใช้งานบนเครื่องของทีมงานเท่านั้น
> อย่าเปิดสู่สาธารณะจนกว่าจะตั้งค่าการยืนยันตัวตน

## วิธีแก้ไฟล์โดยตรง (ทางเลือก)

แก้ไฟล์ JSON ในโฟลเดอร์นี้แล้วรีโหลดหน้าเว็บก็ได้ผลเหมือนกัน

### `members.json`

```json
{
  "slug": "rov-player-01",
  "realName": "ชื่อ-นามสกุล",
  "inGameName": "PPS_IGN_01",
  "role": "นักกีฬา / Player — Mid",
  "category": "rov",
  "game": "rov",
  "bio": "แนะนำตัวสั้น ๆ",
  "image": "/images/members/rov-player-01.jpg",
  "highlights": [],
  "socials": [],
  "order": 1
}
```

| ฟิลด์ | ค่าที่ใช้ได้ | คำอธิบาย |
| --- | --- | --- |
| `slug` | อักษรละติน/ตัวเลข/ขีด | URL ของหน้า → `/members/<slug>` (ห้ามซ้ำ) |
| `category` | `organization` · `rov` · `freefire` · `staff` | หมวดหมู่ที่ใช้กรองในหน้า /members |
| `game` | `rov` · `freefire` | สายเกม (ใส่เฉพาะนักกีฬา/โค้ช/ผู้จัดการทีม) |
| `image` | path หรือ `null` | `null` = แสดง Placeholder |
| `order` | ตัวเลข | ยิ่งน้อยยิ่งขึ้นก่อน |

### ฟิลด์โปรไฟล์นักกีฬ์ (Player Profile)

| ฟิลด์ | คำอธิบาย |
| --- | --- |
| `nickname` | ชื่อเล่น / ชื่อที่ใช้ในกลุ่ม |
| `rosterType` | ประเภทผู้เล่นในทีม — `starter` = ผู้เล่นตัวจริง · `substitute` = ผู้เล่นตัวสำรอง · `coach` = โค้ช · `manager` = ผู้ควบคุมทีม |
| `age` | อายุ (ตัวเลข) |
| `grade` | ระดับชั้น เช่น `ม.6` |
| `instagram` | ชื่อผู้ใช้ (`ppsesport.official`) หรือ URL เต็ม |
| `publish` | สวิตช์หลัก — ถ้า `false` หน้าโปรไฟล์จะไม่เผยแพร่ข้อมูลส่วนตัว |
| `showAge` | อนุญาตให้แสดง **อายุ** (ต้องกรอกค่าด้วย) |
| `showGrade` | อนุญาตให้แสดง **ระดับชั้น** (ต้องกรอกค่าด้วย) |
| `showInstagram` | อนุญาตให้แสดง **Instagram** (ต้องกรอกค่าด้วย) |

> 🔀 **การจัดลำดับ**: เปิดหน้า `/admin` → แท็บ **สมาชิก** แล้วลากที่หัวหมาย (หรือกดปุ่ม ↑/↓)
> หรือกดปุ่ม "จัดลำดับอัตโนมัติ" เพื่อเรียงตามประเภท: ตัวจริง → ตัวสำรอง → โค้ช → ผู้ควบคุมทีม
> ลำดับที่บันทึกไว้จะถูกใช้แสดงผลบนหน้า `/members` ทันที

> 🔒 **กฎการแสดงผล**: ข้อมูลส่วนตัวจะแสดงบนเว็บไซต์ก็ต่อเมื่อ **กรอกค่าไว้แล้ว**
> **และ** เปิดสวิตช์อนุญาตของฟิลด์นั้นในหน้า Admin เท่านั้น
> ถ้าปิดสวิตช์ ระบบจะไม่แสดงฟิลด์นั้นแม้จะยังมีค่าอยู่ในไฟล์ก็ตาม
> (ค่า `publish` ค่าเริ่มต้นคือ `true` เพื่อไม่ให้ข้อมูลเดิมที่มีอยู่แล้วหายไป)

### slug ภาษาไทย

ถ้าใส่ชื่อภาษาไทยระบบจะสร้าง slug ให้อัตโนมัติ เป็นรูปแบบ
`rov-player-02`, `ff-player-03`, `staff-01` เพื่อให้ URL เป็นภาษาอังกฤษและอ่านง่าย

### `achievements.json`

| ฟิลด์ | ค่าที่ใช้ได้ |
| --- | --- |
| `id` | เช่น `ach-001` (ห้ามซ้ำ) |
| `tournament` | ชื่อรายการแข่งขัน |
| `game` | `rov` · `freefire` |
| `rank` | เช่น `อันดับ 1` |
| `tier` | `champion` · `runner-up` · `third` · `top8` · `qualify` (กำหนดสีป้ายอันดับ) |
| `scope` | `school` · `regional` · `national` · `international` |
| `date` | `YYYY-MM-DD` (ใช้กรองตามปี) |
| `teamName` | ชื่อทีมที่เข้าร่วม |
| `image` | path หรือ `null` |

### `games.json`

| ฟิลด์ | คำอธิบาย |
| --- | --- |
| `cover` | ภาพปกเกม (แนะนำ 1600 × 900 px, 16:9) |
| `logo` | โลโก้เกม **ขนาด 1:1** (แนะนำ 400 × 400 px PNG โปร่งใส) — เว้นว่างจะใช้ตราข้อความอัตโนมัติ |

### `hero.json`

| ฟิลด์ | คำอธิบาย |
| --- | --- |
| `images` | รูปพื้นหลังหน้าแรก (array ของ path) — เลื่อนไปทางซ้ายแบบไม่มีจุดหยุด |

วางไฟล์ไว้ที่ `public/images/hero/` แล้วกรอก path ทีละบรรทัดในหน้า Admin

### `branding.json`

| ฟิลด์ | คำอธิบาย |
| --- | --- |
| `schoolLogo` | โลโก้โรงเรียน (1:1, PNG โปร่งใส) — แสดงมุมซ้ายบน |
| `teamLogo` | โลโก้ทีม (แนวนอน, PNG โปร่งใส) — แสดงมุมซ้ายบน |
| `teamName` / `schoolName` / `tagline` | ข้อความที่แสดงในหัวเว็บไซต์ |

วางไฟล์โลโก้ไว้ที่ `public/images/branding/`

## ⚠️ เรื่อง Hosting

การเขียนไฟล์ใช้ได้เฉพาะเซิร์ฟเวอร์ที่มีระบบไฟล์เขียนได้
(`npm run dev` / `npm run start` บนเครื่องหรือ VPS)

ถ้าจะ deploy บน **Vercel** (filesystem เป็น read-only) ต้องเชื่อมฐานข้อมูล
**Supabase** แทน — ดูหัวข้อ "การเชื่อมต่อ Supabase" ใน README หลัก
