# ภาพพื้นหลังหน้าแรก (Hero)

วางรูปพื้นหลังหน้าแรกไว้ที่โฟลเดอร์นี้ แล้วไปที่หน้า `/admin`
แท็บ **โลโก้ทีม/โรงเรียน** → ช่อง "ภาพพื้นหลังหน้าแรก" → ใส่ path ทีละบรรทัด

รูปจะเคลื่อนไหวไปทางซ้ายอย่างต่อเนื่อง (ไม่มีจุดหยุด) และแสดงเป็นฉากหลัง
ของหน้าแรก โดยมีไล่สีขาวทับเพื่อให้ตัวอักษรอ่านออกชัด

## ขนาดแนะนำ

| ขนาด | สัดส่วน | หมายเหตุ |
| --- | --- | --- |
| 1600 × 1000 | 8:5 | แนะนำ — กรอบบนจอกว้าง |
| 1920 × 1080 | 16:9 | ได้ แต่จะเห็นน้อยลงในแนวตั้ง |

## รูปแบบไฟล์

`.jpg` · `.jpeg` · `.png` · `.webp` · `.avif`

## คำแนะนำ

- ใช้รูปที่มีพื้นที่เรียบ (เช่น ภาพทีม, ภาพเวที, ภาพมุมสนาม) เพราะจะถูกครอบด้วยไล่สีขาว
- ความสว่างของรูปควรคล้ายกัน เพื่อไม่ให้หน้าเว็บกะพริบเวลาเลื่อน
- ใส่ 3–5 รูปก็พอ (ระบบจะทำรอบต่อเนื่องให้อัตโนมัติ)
